# 06. MVP 개발 우선순위

평가 기준: 페이지 조회수가 아니라 **JAPAN FINDS 방문자 중 겸사겸사에서 실제로 구매 부탁을 등록한 비율**.
그래서 우선순위는 ① 발견 경험 → ② 정확한 상품정보 → ③ 자동 수집·한국어 큐레이션 → ④ 관심 저장 → ⑤ 구매 의향 확인 → ⑥ 겸사겸사 전환 순이다.

## 1. MVP 범위

| 포함 (가장 중요한 다섯 가지) | 제외 |
|---|---|
| 1. 상품 탐색이 가능한 세련된 웹사이트 | 자체 결제 |
| 2. 상품 상세페이지 | 실제 상품 주문 |
| 3. 일본 신상품 후보 자동 수집 | 배송·물류관리 |
| 4. AI 한국어 번역·분류 + 관리자 승인 | 직접 구매대행 |
| 5. 겸사겸사 구매 부탁으로 연결되는 UI | 고도화된 개인화 추천 |
| (+) 관심 상품 저장(브라우저) | 대규모 가격 추적 |
| (+) 검증된 상품에 한한 가격 비교 | 복잡한 회원 등급 |
| (+) 구매 부탁 출시 알림 신청(연동 전 대체) | 여행자 매칭 자체 구현 |

## 2. Phase별 작업

우선순위: P0 = 없으면 출시 불가 · P1 = 출시 때 있어야 함 · P2 = 출시 후 가능

### Phase 3. 자동 수집

| 우선 | 작업 | 산출물 | 완료 기준 |
|---|---|---|---|
| P0 | 허용 경로가 확인된 소스 1개부터 수집기 구현 | Python 수집기 | 후보가 `product_candidates`에 중복 없이 적재 |

| P1 | 소스 확대 / 허용 안 되는 사이트는 URL 수동 등록 | 어댑터 추가 · 수동 등록 폼 | 소스별 방식이 `docs/05`의 판정과 일치 |
| P0 | **일정·소식 수동 등록** (URL 한 건 + CSV 일괄) | `/admin` 일정 등록 · CSV 양식 | 원제·날짜·장소·출처 URL·한국 이용 범위를 넣어 `events`에 등록, 같은 URL 중복 차단 |
| P1 | **일정·소식 자동 수집** — 허용이 확인된 소스(PR TIMES RSS 등)에서 팝업·발매 공지를 일정 후보로 | 수집기 일정 분기 | 제목·게시일·링크만 저장, 본문·이미지 미저장, 관리자 승인 후 게시 |

| P2 | 공식 뉴스(산리오 등) 제목·날짜·링크 수집 | 어댑터 | **법률 검토 통과 후에만**. 운영사 허가 문의 결과 반영(`docs/07`) |

소스별 수집 가능 여부와 방식은 `docs/05_자동수집_아키텍처.md`의 조사 결과를 따른다.
일정·소식은 덕비서 벤치마크(`docs/07_덕비서_벤치마크.md`)에서 나온 범위다. 덕비서도 자동(`auto-`)과 수동(`csv-`)을 섞어 쓰는 것으로 보이므로, **수동 등록을 먼저 만들어 범위를 채우고** 허용이 확인된 소스부터 자동으로 옮긴다.

## 3. 출시 전 체크리스트

**보안**
- [ ] `/admin`이 인증 없이 열리지 않는다 (robots 차단 + noindex + 인증 3중)
- [ ] API 키·service role 키가 환경변수에만 있고 저장소·브라우저 번들에 없다
- [ ] RLS: 익명 키로 draft 상품·후보·로그·이벤트가 조회되지 않는다
- [ ] 겸사겸사로 넘기는 쿼리에 개인정보가 없다 (상품정보와 ref만)
- [ ] 알림 신청 연락처 수집에 동의 절차와 처리방침이 있다

**데이터 검증**
- [ ] 게시 상품마다 검증된 공식 출처가 1개 이상 있다
- [ ] 모든 가격에 확인 시각이 있고, 임의로 만든 가격이 없다
- [ ] 가격 비교는 동일 상품으로 확인된 것만 나온다
- [ ] 한정 여부가 불확실한 상품은 '한정 여부 확인 중'으로 표시된다
- [ ] '판매량 TOP'·'인기' 등 데이터 없는 순위 표현이 없다
- [ ] 사용권이 확인되지 않은 이미지가 없다
- [ ] 운영 환경에 데모 데이터가 노출되지 않는다 (또는 명확히 표시된다)
- [ ] 수집 방식이 각 사이트의 약관·robots.txt 판정과 일치한다

**모바일·품질**
- [ ] 목록 2열 그리드, 하단 탭바·고정 CTA가 safe-area에서 가려지지 않는다
- [ ] 한글 줄바꿈: 단어 중간 끊김·한 단어만 남는 줄·잘린 제목 없음
- [ ] 로그인 없이 탐색·상세·저장이 된다
- [ ] 상세 페이지가 서버 렌더링되고 제목·설명·구조화 데이터가 들어 있다
- [ ] 겸사겸사 주소가 없을 때 '출시 알림 받기'로 바뀐다

## 4. 미결 사항 (결정이 필요한 것)

| # | 결정할 것 | 왜 필요한가 |
|---|---|---|
| 1 | 서비스명 확정 (JAPAN FINDS는 가칭) · 도메인 | 로고, SEO 제목, 배포 |

| 4 | 출시 알림 신청 때 받을 연락처 종류(이메일·휴대폰·카카오)와 개인정보 처리방침 | `notify_requests`, 동의 문구 |

| 7 | 환율 제공처와 갱신 주기 | 예상 원화가 표시 |
