## 표기 규칙

| 표기 | 뜻 |
|---|---|
| **[직접]** | curl로 직접 요청해 응답 코드·본문을 받은 것 |
| **[문서]** | 공식 문서·약관 페이지를 받아 **요약 도구 또는 텍스트 추출로 읽은 것**. 조항 문구는 원문 대조 전이다 |
| **[제3자]** | 블로그·검색 요약으로만 본 것. 사실로 쓰지 말 것 |
| 차단됨 | 403/429/503/타임아웃. 우회하지 않았다 |

요청에 쓴 User-Agent: `Mozilla/5.0 (compatible; JapanFindsResearch/0.1; feed availability check)`. 소스당 요청은 2~6회.

판정 기준 — **바로 가능**: 키 없이 응답이 오고, robots가 막지 않으며, 읽은 범위의 약관에 자동 취득 금지가 없는 것. 단 어느 소스든 **제목·날짜·링크만 쓰고 본문·이미지는 복제하지 않는다**는 전제다(거의 모든 사이트가 무단 전재를 금지한다).
