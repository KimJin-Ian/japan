# 07. 덕비서 벤치마크 — 무엇을, 어디서 가져오는가

대상: https://deokbiseo.kr/ (확인일 2026-11-13, 브라우저로 공개 페이지만 열람)
확인 범위: `/ip/sanrio` 본문, 이벤트 상세 약 50건의 외부 링크, `/ip/chiikawa`·`/ip/chainsawman`·`/ip/yorushika`, 홈, `/guide/store/chiikawamarket`, `robots.txt`, `sitemap.xml`.

> **확인**이라고 적은 것은 페이지에서 직접 본 것이고, **추정**이라고 적은 것은 겉으로 드러난 흔적으로 짐작한 것이다. 덕비서 내부 구현(수집기·주기·저장 구조)은 볼 수 없으므로 전부 추정이다.

## 1. 덕비서가 보여주는 것

덕비서는 스스로를 "한국 팬을 위해 공식 공지·판매처 정보를 정리하는 독립 서비스"라고 소개한다. 상품을 팔지 않고, **상품 단위가 아니라 '공지(일정) 단위'**로 정보를 쌓는다.

| 구성 | 내용 (확인) |
|---|---|
| IP 허브 `/ip/{이름}` | 산리오·요루시카·체인소맨·치이카와·즛토마요 5개. IP 소개(출처 링크 포함), 주요 캐릭터, "일본 굿즈 한국에서 사는 법", 일정 목록(진행 중 / 예정 / 종료(최근 60일) / 소식) |
| 일정·소식 카드 | 기준일 종류(발매일·시작일·행사 종료·예약 마감·추첨 마감·접수 마감) · 날짜 · **D-day** · 상태(진행 중·예정·마감 임박) · 종류(팝업·이벤트 / 발매·출시 / 예약 시작 / 티켓·응모 / 재판·재입고) · 한국어 제목 · 관련 캐릭터 |
| 한국 이용 범위 | `일본 현지 전용` · `한국 직배송 불가` · `온라인·현지 등 조건별 상이`. 범위를 원문에서 직접 확인한 경우 **"근거: 공식 원문 인용"** 표시 |
| 이벤트 상세 `/events/{id}` | 한국어 요약, **원제(일본어)**, 공식 출처 이름, **공지 확인 시각 · 링크 확인 시각**, 다음 일정, 한국에서 구매·응모(이용 범위·한국 직배송·조건), 장소, 일정 목록, **일정·조건 변경 내역(이전 → 변경)**, 덕비서 정보 수정 시각, "공식 원문과 대조하기 / 공식 페이지 열기" 버튼, 같은 IP의 다른 일정 |
| 구매 가이드 | 직배송 / 배송대행 / 구매대행 3경로 비교표: 가능한 쇼핑몰, 내는 돈 항목, 업체별 수수료·무게별 배송비(업체명과 **확인일** 표기), 관부가세, 장점, 주의. 5,000엔·1kg 계산 예시("실제 견적이 아님" 명시) |
| 관부가세 안내 | 미화 150달러 이하 자가사용 면세 기준을 관세청 링크와 함께 설명 |
| 스토어·응모 가이드 | `/guide/store/{sanrio, chiikawamarket, animate, chiikawaland}`, `/guide/apply/lawson-pia`. 각 스토어 약관·배송 안내에서 해외 배송·결제·회원 조건을 옮기고 조항마다 출처 링크와 확인일을 붙임 |
| 홈 | 날짜 표시, IP 탭, 필터(오늘·이번 주·마감 임박·종료 / 국내 5·일본 380 / 종류별) |
| SEO | JSON-LD(`CollectionPage`·`WebPage`·`Organization`·`WebSite`·breadcrumb), `sitemap.xml`, 이벤트별 OG 이미지(`/og/events/{id}` — 자체 생성 추정) |
| 이미지 | 목록·상세 본문에 **`<img>`가 하나도 없다**(확인). 공식 이미지를 싣지 않고 글과 링크만 쓴다 |

사이트맵 규모(2026-11-13 확인): 이벤트 369건 · IP 5개 · 가이드 5개 · 홈. `robots.txt`는 `/admin`, `/api/`, 로그인 콜백 경로를 막고 나머지는 허용한다.

### 수집 방식 (추정)

1. 공식 뉴스 **목록**을 주기적으로 읽는다. 산리오 뉴스 페이지는 WordPress 기반이고(`robots.txt`의 `/wp-admin/`, 목록의 `item.title.rendered` 바인딩 — 확인), 목록이 JSON으로 불러와지는 구조다. 덕비서가 그 JSON을 읽는지 HTML을 읽는지는 확인하지 못했다.
2. 가져오는 것은 **제목·게시일·링크·카테고리** 정도이고, 한국어 제목·요약은 자체 작성(LLM 사용 추정)한다. 근거: 자동 수집 항목의 설명에 "원문 제목과 확인된 일정으로 자동 정리했으며"라고 적혀 있고(확인), 요약이 얕은 항목은 "산리오 공식 뉴스에 올라온 발매·출시 공지입니다" 한 줄뿐이다(확인).
3. 원문 본문·이미지는 싣지 않는다(확인). 대신 "공식 원문 보기"로 내보낸다.
4. 링크가 살아 있는지 따로 점검한다 — "링크 확인" 시각이 "공지 확인" 시각과 별도로 찍혀 있다(확인).
5. 공지가 바뀌면 이전 값과 바뀐 값을 남긴다(확인). 감지 방법은 재수집 비교로 추정.
6. 치이카와 마켓은 상품 데이터의 `海外NG` 태그를 인용한다(확인). 치이카와 마켓은 Shopify 기반이고 `/products.json`이 열려 있어(`docs/05` 확인) 그 데이터를 읽는 것으로 추정된다. **단 치이카와 마켓 약관은 자동 취득을 금지한다(`docs/05`).** 덕비서가 허가를 받았는지는 알 수 없다.

## 3. 우리도 같은 정보를 모으려면

사용자 목표: "덕비서가 모으는 정보는 우리도 다 모으고 싶다."
원칙은 그대로다 — 약관·robots가 허용한 경로만 쓰고, 본문·이미지는 복제하지 않는다. 그 안에서 같은 범위를 채우는 방법은 아래와 같다.

| 소스 | 판정 | 근거 (확인일 2026-11-13) | 가져올 것 / 하지 말 것 |
|---|---|---|---|
| 산리오 공식 뉴스 `sanrio.co.jp/news` | **주의 — 사실 정보만 자동, 법률 검토 후** | `robots.txt`는 `/wp-admin/`만 차단, 사이트맵 2개 공개. `legal_notices`는 개인적 이용 외 복제·배포, **데이터를 뽑아 다른 사이트에서 쓰는 것**, 무단 전재를 금지. 자동 수집·AI 조항은 없음 | 제목·게시일·링크·카테고리만. 한국어 요약은 자체 작성. 이미지·본문 문장 복제 금지. 사이트맵(`wp-sitemap.xml`)으로 새 글을 찾으면 요청 수를 줄일 수 있음(추정). "제목+링크 색인"이 '데이터 추출 후 이용'에 해당하는지는 **법률 검토 필요** |
| 퓨로랜드·하모니랜드 | 미확인 → 수동 | robots·약관 확인 안 함 | 수동 CSV 등록부터. 확인 후 재판정 |
| 치이카와 마켓 | **불가(자동) → 수동 / 허가 요청** | 약관이 사전 허가 없는 자동 취득 금지(`docs/05`) | 관리자가 URL을 등록하고 사람이 읽어 입력. 운영사에 수집 허가 문의 |
| 포켓몬센터 온라인 | **불가(자동) → 수동** | 약관 제6조가 크롤링·스크레이핑 금지(`docs/05`) | 수동 URL 등록 |
| 반다이 가샤폰 | **불가(자동·AI) → 수동, LLM 분석 제외** | 자동 취득·무단 전재·AI 2차 이용 금지(`docs/05`) | 사람이 읽고 직접 입력 |
| PR TIMES | **가능 (RSS)** | robots 전체 허용, 전체·기업별 RSS 동작(`docs/05`) | 제목·링크·요약·기업명·발행일. 이미지는 싣지 않음 |
| Yahoo! 쇼핑 API | **가능 (API), 상업 이용 조건 확인 전제** | 엔드포인트·필드 확인, 크레딧 표시 의무(`docs/05`) | 상품명·가격·JAN·판매자. 가격 재확인용 |
| 라쿠텐 API | 보류 | 공식 사이트 503으로 미확인(`docs/05`) | — |
| 아티스트·작품 공식 사이트, 티켓(l-tike·pia) | 미확인 → 수동 | 사이트별 확인 필요 | 수동 CSV 등록 |
| 배송대행·구매대행 수수료, 관세 기준 | **수동** | 업체 안내 페이지를 사람이 읽고 확인일과 함께 기록 | 표로 옮기되 출처 링크·확인일 필수. 금액은 바뀔 수 있음을 표기 |

### 약관을 어기지 않고 같은 범위를 채우는 3단 경로

```
① 자동 (허용 확인된 것)          ② 수동 일괄 등록                 ③ 운영사 허가 요청
PR TIMES RSS                     관리자용 CSV 업로드                치이카와 마켓 · 산리오 등
Yahoo! 쇼핑 API                  (제목·원제·날짜·장소·출처 URL)      "제목·일정·링크만 싣고 원문으로
산리오 뉴스 제목·날짜·링크        + URL 한 건 등록 폼                 보낸다"는 조건으로 문의
 (법률 검토 통과 시)              ↑ 덕비서도 csv- 로 같은 일을 함     허가 나면 ①로 승격
        │                                │                                │
        └───────────────┬────────────────┴────────────────────────────────┘
                        ▼
          event_candidates / product_candidates → LLM 정리(허용 소스만) → 관리자 검수 → 게시
```

- ①만으로는 덕비서 범위의 일부만 채워진다. **빈 곳은 ②로 메운다.** 덕비서도 체인소맨·요루시카는 대부분 수동(`csv-`)이다.
- ②를 싸게 만드는 것이 핵심이다: CSV 양식 고정, 출처 URL 중복 검사, 링크 점검 자동화(링크 점검은 한 번의 HEAD/GET이라 약관 부담이 낮다 — 단 금지 사이트는 빈도를 낮춘다).
- ③은 한 번의 메일로 끝나는 일이다. 허가를 받으면 그 소스가 자동으로 넘어간다.
- 가샤폰처럼 AI 이용까지 금지한 소스는 LLM에 원문을 넣지 않는다.

## 4. JAPAN FINDS에 반영한 것

| 덕비서에서 본 것 | JAPAN FINDS 반영 | 위치 |
|---|---|---|
| 공지 단위 일정·소식 | **일정·소식 타입 `EventItem`** (release·popup·campaign·preorder·lottery·restock) | `src/lib/types.ts`, `/schedule`, DB `events` |

| 직배송/배송대행/구매대행 비교 | 상품 상세 **"한국에서 구하는 방법"** — 직배송 · 배송대행 · 구매대행 · **겸사겸사 부탁**. 네 번째 경로가 우리 전환 지점 | `/products/[slug]` |

## 5. 확인하지 못한 것

- 덕비서의 실제 수집기 구조·주기, LLM 사용 여부, 운영사 허가 여부.
