# 03b. 디자인 시스템 초안

방향: **"일본틱하고 귀엽지만, 촌스럽지 않고 세련된 감성."**
무드: 도쿄의 귀여운 잡화점 · 캐릭터 편집숍 · 한정 굿즈 셀렉트숍. 일본 여행 가기 전 쇼핑리스트를 구경하는 느낌.
두 가지를 동시에 지킨다 — ① 귀엽고 일본틱한 감성 ② 실제로 쓰기 편한 정보 탐색.

토큰의 실제 값은 `src/app/globals.css`의 `@theme` 블록이 기준이다. 아래 표는 그 값을 그대로 옮긴 것이다.

## 1. 컬러

### 바탕·글자

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `paper` | `#ffffff` | 카드, 입력칸 |
| `cream` | `#fffaf2` | 페이지 바탕 |
| `cream-deep` | `#f8efe0` | 보조 바탕, 이미지 자리 |
| `ink` | `#3a3331` | 본문·제목 (차콜) |
| `ink-soft` | `#6b615d` | 보조 글자 |
| `mute` | `#9a8f89` | 확인 시각 등 작은 보조 정보 (웜 그레이) |
| `line` | `#efe6da` | 테두리·구분선 |
| `latte` | `#b89f8c` | 라이트 브라운 장식 |

### 포인트 (파스텔)

| 토큰 | 값 | 쓰임 |

| `pink` | `#ffdfe3` | 스티커·카드 톤 |
| `pink-deep` | `#f7a8b4` | 깅엄 무늬, 하트 |

| `mint` | `#d6f2e6` | 스티커·카드 톤 (한 방울만) |
| `mint-deep` | `#2f7d62` | 민트 바탕 위 글자, '확인됨' |

규칙
- 한 화면에 파스텔은 많아도 **바탕은 크림 하나**. 파스텔은 스티커·테이프·이미지 자리에만 쓴다.
- 형광색·진한 원색 금지. 코랄은 주 CTA와 가격 차이 강조에만.
- 상품 이미지 자리의 색(`visual.tone`)은 pink · peach · butter · mint · sky · lilac 6가지.

## 2. 타이포그래피

| 역할 | 글꼴 | 토큰 | 규칙 |
|---|---|---|---|
| 제목(헤드라인·섹션 제목) | **Jua** | `--font-display` | 통통하고 사랑스러운 인상. 굵기가 하나뿐이라 `font-bold`를 덧씌우지 않는다. 차콜색으로만 써서 유아틱해지지 않게 |
| 본문 | **Noto Sans KR** | `--font-sans` | 400 / 500 / 700. 가격·날짜는 700 |
| 일본어 원문·라틴 포인트·로고 | **Zen Maru Gothic** | `--font-maru` | 둥근 고딕. 스티커의 일본어(`日本限定`), 원제, 로고 |

글꼴 대체 순서(`globals.css`): 본문은 `Apple SD Gothic Neo → Malgun Gothic → Hiragino Sans → Yu Gothic UI`, 마루는 `Hiragino Maru Gothic ProN → Yu Gothic UI`.

| 단계 | 크기(모바일) | 글꼴 |
|---|---|---|
| 히어로 | 30~34px | Jua |
| 섹션 제목 | 20~22px | Jua + 마스킹테이프 |
| 카드 상품명 | 14px / 2줄 | Noto Sans KR 500 |
| 가격 | 16px | Noto Sans KR 700 |
| 스티커 | 11px (일본어 10px) | Noto Sans KR 700 / Zen Maru Gothic 700 |
| 확인 시각·주석 | 11~12px | Noto Sans KR 400, `mute` |

한국어 줄바꿈: `word-break: keep-all`, 제목은 `text-wrap: balance`, 문단은 `text-wrap: pretty`. 한 단어만 남는 줄과 잘린 제목이 없는지 캡처로 확인한다.

## 3. 형태

| 항목 | 값 |
|---|---|
| 카드 모서리 | 20px |
| 버튼·스티커 모서리 | 999px (알약) |
| `shadow-soft` | `0 1px 2px rgb(120 90 70 / 0.05), 0 6px 18px -8px rgb(120 90 70 / 0.18)` — 기본 카드 |
| `shadow-pop` | `0 2px 0 rgb(120 90 70 / 0.08), 0 14px 28px -12px rgb(120 90 70 / 0.28)` — 카드 hover |
| 선 | 1~1.5px, `line` 색. 강한 검정 선 금지 |

그림자는 회색이 아니라 **따뜻한 갈색 계열**이라 크림 바탕에서 탁해 보이지 않는다.

## 4. 컴포넌트

### 스티커 배지 (`.sticker`)

작은 종이 스티커처럼 보이는 알약 배지. **한국어 + 일본어 원문 병기** — 일본 매장에서 실제로 보게 될 표기를 미리 익히게 한다.

| 배지 | 표기 | 색(바탕) |
|---|---|---|
| 일본 한정 | `일본 한정 日本限定` | pink |
| 지역 한정 | `지역 한정 地域限定` | mint |
| 매장 한정 | `매장 한정 店舗限定` | sky |
| 기간 한정 | `기간 한정 期間限定` | butter |
| 수량 한정 | `수량 한정 数量限定` | lilac |
| 신상품 | `NEW 신상품` | peach |
| 곧 출시 | `D-7 곧 출시` | butter |
| 한국 미출시 | `한국 미출시` | 흰 바탕 + 테두리 |
| 한정 여부 확인 중 | `한정 여부 확인 중` | cream-deep, 회색 글자 |
| 판매 종료 | `판매 종료` | 회색 |
| 데모 | `DEMO 예시` | 흰 바탕 + 점선 테두리 |

- 유형별 색 배정은 초안이다. 코드(`LimitedTag`)와 다르면 코드에 맞춰 이 표를 고친다.
- 카드에는 스티커 최대 2개 + `+N`. 상세에서는 전부 보여 준다.
- **'인기상품' 배지는 실제 조회·저장 데이터가 쌓이기 전에는 쓰지 않는다.**
- 색만으로 구분하지 않는다 — 항상 글자가 있다.

### 마스킹테이프 섹션 제목 (`.tape`)

제목 글자 아래쪽에 반투명 테이프를 살짝 기울여(-1.2°) 붙인 모양. 가장자리는 손으로 찢은 듯 불규칙하게 자른다. 섹션마다 `--tape` 색을 butter · pink · mint · peach로 돌려 써서 잡지 코너 제목처럼 보이게 한다.

### 버튼 (`.btn`)

| 종류 | 모양 | 쓰임 |
|---|---|---|
| Primary (`.btn-primary`) | 코랄 바탕 · 흰 글자 · 아랫면 3px `coral-deep` (살짝 입체) | 화면당 하나. "일본 여행자에게 부탁하기" |
| Secondary (`.btn-secondary`) | 흰 바탕 · 1.5px `line` 테두리 | 저장, 필터, 더 보기 |

hover 시 2px 떠오르며 1.02배(통통 튀는 이징), 누르면 1px 내려가며 0.98배.

구매 부탁 CTA는 업무적이지 않게: "내가 갖고 싶은 걸 누군가에게 부탁해 보는" 말투. 버튼 위에 한 줄 보조 문구("도쿄에 가는 여행자가 대신 사다 줘요")와 작은 캐리어·리본 아이콘 하나.

### 카드 (`.card`)

- 흰 바탕 · 20px 모서리 · `shadow-soft`. hover 시 4px 떠오르고 -0.4° 기울며 `shadow-pop`.
- 이미지가 주인공: 카드 위쪽 정사각형, 파스텔 톤 바탕. 좌상단 스티커, 우상단 하트.
- 아래: 브랜드(작게) → 상품명 2줄 → 일본 가격 + 예상 원화 → 출시일·지역.
- 작은 굿즈 패키지처럼 보이되, 정보 4줄의 순서는 모든 카드에서 같다.

### 검색창

크고 둥근 알약(높이 48px 이상), 문구는 "어떤 일본 상품을 찾고 있나요?". 왼쪽에 돋보기 아이콘 하나.

### 바탕 패턴

| 패턴 | 클래스 | 쓰는 곳 |
|---|---|---|
| 도트 포장지 | `.dots` (코랄 13% 점, 18px 간격) | 히어로, 빈 상태 |
| 깅엄 체크 | `.gingham` (핑크 16%, 20px) | 관심 상품 머리, 구매 부탁 영역 |

한 화면에 패턴은 한 군데만. 글자가 올라가는 곳에는 농도를 더 올리지 않는다.

### 장식 아이콘·일러스트

별 · 하트 · 리본 · 반짝임 · 쇼핑백 · 작은 캐리어. 사용 한도:

- 화면당 장식은 **3개 이하**, 한 섹션에 1개.
- 정보를 전달하는 아이콘(검색·하트·공유)과 장식을 섞지 않는다.
- 장식에는 `aria-hidden`. 내용보다 튀면 뺀다.
- 사용권이 확인되지 않은 상품 이미지는 쓰지 않고 자체 일러스트(`ProductVisual`)로 대체한다.

## 5. 접근성

| 항목 | 규칙 |
|---|---|
| 글자 대비 | 본문 4.5:1 이상. `ink`(#3a3331)는 cream·paper 위에서 충족. **코랄 글자는 반드시 `coral-deep`** — `coral`(#f0705f)은 흰 바탕 위 글자로 쓰지 않는다 |
| 파스텔 위 글자 | 스티커 글자는 `ink` 또는 각 색의 deep 값. 파스텔끼리 겹쳐 글자를 올리지 않는다 |
| 터치 영역 | 최소 44×44px. 스티커는 누르는 요소가 아니다(필터 칩은 별도 44px 높이) |
| 포커스 | 2.5px `coral-deep` 외곽선, 2px 띄움 |
| 움직임 | `prefers-reduced-motion: reduce`면 전환·애니메이션·부드러운 스크롤을 모두 끈다 |
| 색 의존 금지 | 상태(한정 유형·판매 종료·확인 중)는 색과 글자를 함께 쓴다 |
| 일본어 | 일본어 원문에는 `lang="ja"`를 붙여 읽기 프로그램이 올바르게 읽게 한다 |

## 6. 피해야 할 것

- 차갑고 IT 서비스 같은 느낌(회색 바탕, 날카로운 모서리, 파란 링크투성이)
- 무겁고 남성적인 톤, 네온 컬러
- 정신없는 레이아웃, 저가 쇼핑몰처럼 보이는 빨간 할인 딱지·깜빡이는 배너
- 올드한 일본풍(붓글씨·부채·후지산 클립아트)
- 지나치게 유아틱한 디자인(장난감 같은 글꼴 남발, 원색 무지개)
- 정보가 불편할 만큼 많은 장식
- 특정 캐릭터·브랜드의 그림체나 사이트를 그대로 본뜨는 것

## 7. 미결

- 스티커 유형별 색 배정 확정(위 표는 초안).
- 로고 시안(현재는 Zen Maru Gothic 글자 로고).
- 자체 일러스트 스타일 가이드(모티프 16종의 선 굵기·채움 규칙).
- 다크 모드는 만들지 않는다(크림 바탕이 정체성). 필요해지면 다시 정한다.
