# 03. 화면 설계 (모바일 중심)

## 1. 디자인 원칙

| 항목 | 규칙 |
|---|---|
| 방향 | **"일본틱하고 귀엽지만, 촌스럽지 않고 세련된 감성."** 도쿄의 귀여운 잡화점·캐릭터 편집숍을 구경하는 느낌. 세부 값은 [`03b_디자인시스템.md`](03b_디자인시스템.md)가 기준 |
| 색 | 바탕 크림(`#fffaf2`) · 카드 화이트 · 글자 차콜(`#3a3331`) · 테두리 웜 베이지. 포인트는 파스텔(핑크·피치·버터·민트·스카이·라일락)과 코랄. 코랄은 주 CTA와 가격 차이 강조에만, 흰 바탕 위 코랄 글자는 `coral-deep` |
| 글꼴 | 제목 Jua(통통한 헤드라인) · 본문 Noto Sans KR · 일본어 원문과 로고 Zen Maru Gothic |
| 형태 | 카드 모서리 20px, 버튼·배지는 알약형, 따뜻한 색의 은은한 그림자. 버튼·카드는 hover 때 살짝 통통 튄다 |
| 분위기 장치 | 섹션 제목 뒤 **마스킹테이프**, 스티커 같은 배지, 히어로의 도트 포장지 패턴. 장식은 화면당 3개 이하 — 내용보다 튀면 뺀다 |
| 상품 이미지 | 화면의 주인공. 카드에서 이미지 비중을 가장 크게. 사용권이 확인되지 않은 이미지는 쓰지 않고 자체 일러스트로 대체 |
| 한정 태그 | 스티커 배지에 **한국어 + 일본어 원문 병기** — `일본 한정 日本限定` · `지역 한정 地域限定` · `매장 한정 店舗限定` · `기간 한정 期間限定` · `수량 한정 数量限定`. 확인 전이면 회색 `한정 여부 확인 중` |
| 피할 것 | 차가운 IT 서비스 느낌, 네온, 저가 쇼핑몰식 딱지, 올드한 일본풍, 지나친 유아틱함 |
| 가격 | 일본 가격(JPY)을 먼저, 예상 원화는 보조. **모든 가격 옆에 확인 시각**. 환산가에는 '예상', 미포함 비용 안내 |
| 정직한 표기 | 판매량 순위 표현 금지. '이번 주 주목할 상품' · '에디터 추천' · '최근 등록'처럼 검증 가능한 기준만 |
| 한글 줄바꿈 | 단어 단위(`word-break: keep-all`), 안내문은 균형 잡힌 줄바꿈, 한 단어만 남는 줄·잘린 제목 없게 |
| 데모 표시 | 예시 상품에는 카드·상세 모두 `DEMO 예시 데이터` 표시, 사이트 상단에 안내 띠 |
| 터치 | 버튼·탭 최소 44px, 하단 고정 요소는 safe-area 고려 |

## 3. 화면별 레이아웃

### 3-1. 홈 `/`

```
[헤더]
[메인 배너]  일본에서만 만날 수 있는
            특별한 상품들            (크림 바탕 + 도트 패턴, Jua 큰 제목)
            [ 🔍 어떤 일본 상품을 찾고 있나요? ]   (크고 둥근 검색창)
[카테고리 아이콘]  4열 × 2줄 — 파스텔 동그라미 안 미니 일러스트 + 이름
            캐릭터 · 가챠 · 패션 · 뷰티 / 문구 · 생활 · 지역 한정 · 팝업
[섹션 1] 지금 주목할 일본 한정템      전체 보기 ›   (큰 카드 가로 스크롤)
[다가오는 일정]                      일정 전체 ›
            D-2  11.15 발매  하루비요리 겨울 잉크 4색      한국 직배송 불가
            D-3  11.16 마감  오사카 팝업 입장 추첨          일본 현지 전용
            D-7  11.20 발매  모치네코 겨울 머플러 시리즈    (3~4줄, 가까운 날짜순)
[섹션 2] 최근 출시된 신상품           전체 보기 ›   (2열 그리드)
[섹션 3] 캐릭터·가챠 상품             전체 보기 ›   (가로 스크롤)
[섹션 4] 일본 팝업스토어 한정상품     전체 보기 ›   (기간 표시 카드)
[섹션 5] 곧 출시되는 상품             전체 보기 ›   (D-day 표시)
[섹션 6] 한국과 일본 가격 비교        전체 보기 ›   (비교 막대 요약 카드)
[푸터]  서비스 소개 · 정보 출처 원칙 · 데모 안내
[탭바]
```

- 겸사겸사 배너·가입 유도 없음.
- 섹션 제목은 잡지 코너 제목처럼 마스킹테이프를 붙이고, 섹션마다 테이프 색을 바꾼다.
- '다가오는 일정'은 발매·팝업 시작·마감이 가까운 순으로 보여 준다. 각 줄에 한국 이용 범위 배지를 붙인다.
- 섹션 3의 이름은 요구사항 원문이 '캐릭터·가챠 인기상품'이지만, 실제 조회·저장 데이터가 쌓이기 전에는 '인기'를 빼고 표기한다.

### 3-2. 상품 목록 `/products`

```
[헤더]
[검색창]  상품명 · 브랜드 · 캐릭터 (한국어/일본어)
[필터 칩 가로 스크롤] 카테고리 ▾ · 한정 유형 ▾ · 지역 ▾ · 한국 판매 ▾ · 가격대 ▾
결과 24개                         정렬: 최신순 ▾
┌────┐ ┌────┐
│카드│ │카드│   모바일 2열 / 데스크톱 4~5열
└────┘ └────┘
[탭바]
```

- 필터는 하단 시트로 열고, 적용된 필터는 칩으로 남겨 한 번에 해제 가능.
- 정렬: 최신순 · 가격 낮은순 · 가격 높은순. 인기순은 데이터 확보 후 노출.

### 3-3. 상품 상세 `/products/[slug]`

```
[헤더: ‹ 뒤로        공유  ♡]
[이미지 (가로 넘김)]
[한정 태그들]  日本限定 일본 한정 · 店舗限定 매장 한정
브랜드 ›
한국어 상품명
日本語の商品名 (원문, 작게)

┌ 일본 현지 가격 ─────────────────┐
│ ¥1,980 (세금 포함)   약 18,000원  │
│ 판매처 ○○ · 11.10 14:00 확인      │
│ 배송비·세금·수수료 미포함          │
└───────────────────────────┘
┌ 한국에서 살 수 있나요? ──────────┐
│ 한국 공식 판매 없음 / 한국 가격 미확인 │
│ (있으면) 한국가 · 차이 · 비교 막대     │
└───────────────────────────┘
┌ 한정 여부와 근거 ───────────────┐
│ 근거 문장 + 출처 링크 + 확인 시각   │
└───────────────────────────┘
출시일 · 판매 종료일 · 판매 지역
살 수 있는 곳 (매장 / 사이트 목록)
구매 조건·주의사항 (1인 수량 제한 등)

┌ 한국에서 구하는 방법 ────────────┐
│ ① 직배송      이 판매처는 한국 배송 없음 / 가능 / 확인 중 │
│ ② 배송대행    일본 주소로 받아 한국으로 (온라인 판매 상품만) │
│ ③ 구매대행    대행업체가 대신 주문 (판매처 약관 확인 필요)   │
│ ④ 여행자에게 부탁  매장·팝업 한정도 가능 ← 겸사겸사          │
│    ※ 매장 한정·팝업 한정이면 ①~③은 '해당 없음'으로 흐리게   │
└───────────────────────────┘
관련 일정 (이 상품이 나오는 팝업·발매 공지, 있으면)
공식 정보 출처 (링크 · 확인일 · 검증 여부)
관련 상품 (가로 스크롤)

[고정 CTA]  ♡ 저장 │ 일본 여행자에게 구매 부탁하기
            └ 겸사겸사로 이동 · 상품정보 자동 입력
```

- 강조 순서: 한정 여부 → 일본 가격 → 한국 구매 가능 여부 → 판매처 → 출시일 → 구매 조건.
- 겸사겸사 주소가 없으면 CTA가 "구매 부탁 출시 알림 받기"로 바뀐다.
- "한국에서 구하는 방법"은 네 경로를 같은 무게로 정직하게 보여 준다. 매장·팝업 한정처럼 온라인 경로가 막힌 상품에서는 ④만 남고, 이것이 고정 CTA와 같은 행동으로 이어진다. 배송대행·구매대행 업체의 수수료를 싣는다면 업체명·확인일을 붙이고 사람이 확인한 값만 쓴다(프로토타입에는 금액을 넣지 않는다).
- CTA 말투는 업무적이지 않게 — "내가 갖고 싶은 걸 누군가에게 부탁해 보는" 느낌. 깅엄 체크 바탕에 작은 캐리어 아이콘 하나.

### 3-4. 가격 비교 `/compare`

```
[헤더]
일본·한국 가격 비교
같은 상품·모델·용량·옵션으로 확인된 것만 보여드려요.
기준 환율 100엔 = ○○○원 (확인 시각)

┌ 상품명 ──────────────────────┐
│ 일본 ████████░░░░  ¥3,300 (약 30,000원) │
│ 한국 ████████████  42,000원            │
│ 일본이 약 12,000원 저렴 · 각 가격 확인 시각 │
└────────────────────────┘
※ 배송비·세금·구매 부탁 보수는 포함되지 않았습니다.
[탭바]
```

- KR 오퍼의 `sameItemVerified`가 true인 상품만 나온다.
- 프로토타입의 환율은 '데모용 가정 환율'임을 화면에 명시한다. 운영에서는 환율 API 값과 확인 시각을 표시.

### 3-5. 관심 상품 `/saved`

```
[헤더]
관심 상품 3개
이 브라우저에 저장돼요. (로그인 기능은 준비 중)
┌────┐ ┌────┐
│카드│ │카드│
└────┘ └────┘
[탭바]
```

- 위시리스트를 모으는 느낌이 나게: 머리 영역에 깅엄 체크, 카드는 목록과 같은 모양, 저장한 상품의 가까운 발매·종료일을 위에 한 줄로 알려 준다.

### 3-6. 일정·소식 `/schedule`

```
[헤더]
일정·소식
공식 공지에 올라온 발매 · 팝업 · 응모 일정이에요.
[상태 탭]  진행 중 · 예정 · 종료
[종류 칩]  전체 · 발매 · 팝업 · 캠페인 · 예약 · 추첨 · 재입고

┌──────────────────────────────┐
│ 행사 종료        팝업 · 도쿄            │
│ 11.24  D-11      모치네코 시부야 팝업스토어 │
│ [일본 현지 전용] 근거: 공식 원문 인용     │
│ 관련 상품 1개 ›                          │
└──────────────────────────────┘
(카드를 펼치면)
  원제: もちねこ POP UP STORE in 渋谷 …
  요약 · 장소 · 기간
  변경 내역: 종료일 11월 23일 → 11월 24일 (11.10 확인)
  공식 출처 · 공지 확인 11월 7일 19:00 · 링크 확인 11월 13일 06:00
  [공식 원문 보기]
[탭바]
```

- 기준일은 상황에 맞게 고른다: 예정이면 시작일, 진행 중이면 종료일(마감), 추첨·예약은 마감일.
- 한국 이용 범위 배지: `일본 현지 전용` · `한국 직배송 불가` · `조건별 상이` · `한국에서도 가능` · `확인 중`. 원문 문장으로 확인한 경우에만 "근거: 공식 원문 인용"을 붙인다.
- 일정에서 관련 상품으로, 상품 상세에서 관련 일정으로 서로 이어진다.
- 종료된 일정도 지우지 않고 '종료' 탭에 남긴다.

### 3-7. 관리자 `/admin` (비공개)

```
[관리자 헤더]  후보 검수 │ 게시 상품 │ 수집 로그
검수 대기 12 · 승인 · 반려 · 병합

┌ 원문 제목(일본어) · 출처 · 수집 시각 ─────┐
│ 한국어 상품명   [입력칸]       신뢰도 0.92 │
│ 브랜드 / 카테고리 / 한정 유형  신뢰도 표시  │
│ 출시일 / 종료일 / 판매처 / 가격   ⚠ 확인 필요 │
│ 중복 의심: ○○ 상품 [병합]                  │
│ 이미지 사용권: 미확인 ▾                    │
│ [반려]            [출처 열기]  [게시 승인] │
└──────────────────────────┘

수집 로그 표: 대상 · 방식 · 실행 시각 · 성공 여부 · 발견/추가 수 · 재시도 · 오류
```

- 모바일에서도 한 손으로 승인·반려할 수 있게 카드형으로 구성. 데스크톱은 표 + 상세 패널.
- 접근 통제: `proxy.ts` Basic 인증 + robots 차단 + noindex. 메뉴 어디에도 링크하지 않는다.

## 4. 상태 정의

| 상태 | 표시 방식 | 적용 화면 |
|---|---|---|
| 로딩 | 카드 모양 스켈레톤(레이아웃 흔들림 없게) | 목록·관심·상세 일부 |
| 빈 결과 | "조건에 맞는 상품이 없어요" + 필터 초기화 버튼 + 다른 카테고리 추천 | 목록 |
| 관심 상품 없음 | "아직 저장한 상품이 없어요" + 상품 보러 가기 | 관심 |
| 한국 가격 미확인 | 회색 문구 '한국 가격 미확인'. 가격 차이·비교 막대를 그리지 않는다 | 상세·카드 |
| 한정 확인 중 | 회색 태그 '한정 여부 확인 중' + 무엇을 확인 중인지 한 줄 | 카드·상세 |
